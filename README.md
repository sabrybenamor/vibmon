# vibmon

Vibration-based machine-health monitor on Raspberry Pi 5 with an ADXL accelerometer.

Status: work in progress.

## Layout
- `daemon/`  sensor acquisition service
- `hmi/`     PySide6 touchscreen interface
- `models/`  trained models and export scripts
- `yocto/`   Yocto layer and recipes
- `docs/`    journal, schema, metrics, evidence
